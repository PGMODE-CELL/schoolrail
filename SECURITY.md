# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of SchoolRail seriously. If you believe you have found a
security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to the project maintainers. You should
receive a response within 48 hours.

To report a vulnerability, please include:

- Type of issue (e.g., SQL injection, XSS, broken authentication)
- Full paths of source files related to the issue
- Step-by-step instructions to reproduce
- Proof-of-concept or exploit code (if possible)
- Impact of the issue

## Preferred Languages

We prefer all communications to be in English.

## Disclosure Policy

When we receive a security report, we will:

1. Confirm receipt and analyze the report
2. Work on a fix and release timeline
3. Release the fix and publicly disclose the vulnerability

Thank you for helping keep SchoolRail and its users safe.
